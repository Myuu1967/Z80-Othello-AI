negamax とは？ minimax は「自分→最大化・相手→最小化」と別ロジックが必要。 negamax は 相手のスコアを符号反転 ＝ 自分のスコア とみなすことで、 どちらの手番も「自分視点で最大化」という同じコードで書ける再帰探索。
minimax（自分とMAX/MIN別々）
def minimax(board, depth, is_max):
    if depth == 0:
        return evaluate(board)
    if is_max:            # 自分の番
        best = -INF
        for move in moves(board):
            s = minimax(board+move, depth-1, False)
            best = max(best, s)
    else:                 # 相手の番
        best = +INF
        for move in moves(board):
            s = minimax(board+move, depth-1, True)
            best = min(best, s)  # ← 最小化
    return best
negamax（どちらの番も同じコード）
def negamax(board, depth, side):
    if depth == 0:
        return evaluate(board, side)
    best = -INF
    for move in moves(board, side):
        s = negamax(board+move, depth-1,
                    opponent(side))
        best = max(best, -s)
        #             ↑ 符号反転するだけ
        #   相手にとって良い = 自分に悪い


    return best
depth-2 空き ≥ 20マス　negamax α-β　通常手番
depth-3 空き < 20マス　negamax α-β　終盤切替
完全読み 空き ≤ 4マス　石差最大化（符号付き negamax）
